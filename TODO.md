### Domain

- [Custom domains](https://dash.cloudflare.com/?to=/:account/pages/view/jumalegal/domains)
- `Set up a custom domains`
- `jumalegal.com`
- `Continue`
- Add `DNS Records` copied from Cloudflare Pages to Domain gestor:
  - From: `jumalegal.com`
    DNS Record: `CNAME`
    To: `jumalegal.pages.dev`
  - From: `www`
    DNS Record: `CNAME`
    To: `jumalegal.pages.dev`
- `Activate domain` (if `Begin DNS transfer` end)
- Repeat with `www.jumalegal.com`
